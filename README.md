# UkePack AI

> 把你的歌變成小朋友也能練的烏克麗麗練習包。

把 Klangio 等 AI 轉譜工具產出的初稿，整理成 **小朋友 15 分鐘內能開始練** 的烏克麗麗練習包。

## 文件

- [PRD.md](./PRD.md) — 完整產品需求文件 v1.0 Draft
- [docs/](./docs/) — 設計、規則表、教學模板（待建立）
- [samples/](./samples/) — 測試素材 MusicXML / MIDI（待建立）

## 北極星指標

一首歌從匯入到小朋友能彈出第一段，所需時間是否少於 30 分鐘。
