# UkePack 老師使用指南

> **目標讀者**：烏克麗麗老師，需要把一首歌整理成學生可直接練習的 PDF 練習包。  
> **預計閱讀時間**：10 分鐘  
> **預計完成第一份練習包**：< 30 分鐘

## 1. 系統需求

| 項目 | 需求 |
|------|------|
| 瀏覽器 | Chrome / Firefox / Safari（現代版本） |
| 網路連線 | 需要（存取本地或雲端部署的 App） |
| MusicXML 來源 | MuseScore、Noteflight、Finale、Sibelius 匯出的 `.musicxml`、`.mxl` 或 `.xml` |

若您沒有 MusicXML 檔，也可以直接**手動輸入和弦**（見[第 5 節](#5-手動輸入和弦可選)）。

---

## 2. 快速開始：5 步做出第一份練習包

```
① 開瀏覽器 → http://localhost:8000/new
② 填寫曲名 + 選擇來源類型 → 點「建立專案」
③ 上傳 MusicXML 或手動輸入和弦
④ 確認授權（勾選後解鎖 PDF 輸出）
⑤ 點「預覽 PDF」或「下載 PDF」
```

整個流程通常在 **2 分鐘內**完成。

---

## 3. 建立專案

前往首頁點 **「建立新練習包」**，或直接開啟 `/new`。

### 必填欄位

| 欄位 | 說明 | 範例 |
|------|------|------|
| **曲名** | 顯示在 PDF 標題與授權區塊 | 小星星 |
| **素材來源** | 決定 PDF 授權聲明版型 | 公版曲目 |
| **學習者年齡**（選填） | 未來難度建議參考 | 7 |

### 素材來源類型

| 選項 | 適用情況 | PDF 授權聲明 |
|------|---------|-------------|
| **公版曲目** | 著作權過期或 CC0 曲目（如小星星、生日歌） | 無特殊聲明 |
| **Suno Free** | 用 Suno 免費版 AI 生成的曲目 | Non-commercial practice use |
| **Suno Paid** | Suno 付費版生成 | 依 Suno 授權 |
| **自創曲目** | 您自己或學生創作 | 無特殊聲明 |
| **有授權曲目** | 已取得合法授權的商業曲目 | 依授權內容 |
| **私人研究** | 僅供個人研究，**不可分享** | Private study only. Do not distribute. |

> ⚠️ **私人研究**模式下，分享連結功能會被鎖住，PDF 也會強制印上警語。

## 4. 匯入樂譜

建立專案後，進入分析頁，若尚未有曲譜，會看到「📥 尚未匯入曲譜」區塊。

### 步驟

1. 點選「**選擇 .musicxml / .mxl 檔**」
2. 選取您的檔案（≤ 10 MB）
3. 點「**匯入**」按鈕

### 支援格式

| 格式 | 副檔名 | 常見來源 |
|------|--------|---------|
| MusicXML | `.musicxml`、`.xml` | MuseScore（匯出 → MusicXML） |
| 壓縮 MusicXML | `.mxl` | Finale、Sibelius、Noteflight |

### 匯入後系統會自動分析

- 原始 Key、建議 Key（GCEA 友善調性）
- BPM（速度）、拍號、小節數
- 和弦進行、段落結構（前奏 / 主歌 / 副歌）
- 難度等級（Level 1 / 2 / 3）

### 如果匯入失敗

- 確認檔案副檔名是 `.musicxml`、`.mxl` 或 `.xml`
- 確認檔案大小 ≤ 10 MB
- 在 MuseScore 重新「另存為 MusicXML」並再試一次

## 5. 手動輸入和弦（可選）

沒有 MusicXML？沒關係。您可以直接用文字輸入和弦進行。

在分析頁的「尚未匯入曲譜」區塊，或從 API `/api/projects/{id}/chords` 送出：

```
Verse:
C | G | Am | F
C | G | F | C

Chorus:
F | C | G | Am
F | C | G | C
```

### 格式規則

- 每個和弦用 `|` 分隔
- 段落 header 可以用 `Verse:`、`Chorus:`、`前奏:`（系統自動辨識）
- 每行視為一小節或一個短樂句
- 支援標準和弦符號：`C`、`Am`、`G7`、`Cmaj7`（會自動簡化給初學者）

## 6. 理解分析頁

匯入或輸入和弦後，分析頁會顯示以下資訊：

### 6.1 基本資訊卡

| 項目 | 說明 |
|------|------|
| **原始 Key** | 樂譜原本的調性 |
| **建議 Key** | 系統推薦的烏克麗麗友善調性（C / G / F / Am 優先） |
| **BPM** | 速度（從樂譜讀取） |
| **拍號** | 如 4/4、3/4 |
| **小節數** | 樂譜總小節數 |
| **難度等級** | Level 1（入門）、Level 2（初級）、Level 3（中級） |

### 6.2 可彈性分數（0–100）

> 分數越高 = 學生越容易直接上手

分數由 6 個因子加權計算：

| 因子 | 說明 |
|------|------|
| **和弦複雜度** | 使用的和弦種類難度 |
| **BPM** | 速度越快越難 |
| **換和弦頻率** | 每小節換和弦次數 |
| **旋律音域** | 最高最低音距離 |
| **和弦種類數** | 需要學的不同和弦數量 |
| **最高把位** | 最難按法需要按到第幾格 |

**參考標準**：
- 75–100：Level 1，適合完全初學
- 50–74：Level 2，學過基本和弦者
- 0–49：Level 3，進階學生

### 6.3 段落結構

系統會嘗試自動辨識**前奏（Intro）/ 主歌（Verse）/ 副歌（Chorus）**，顯示每個段落的小節範圍。

手動輸入和弦時，您可以用 `Verse:` / `Chorus:` header 明確標注。

### 6.4 刷法建議

點擊 **Level 1 / 2 / 3** 標籤，可以切換查看對應難度的刷法建議。  
切換後系統會自動儲存您選擇的難度等級（影響 PDF 輸出）。

5 種刷法由易到難：

| 刷法 | 符號 | 適合程度 |
|------|------|---------|
| 全下刷 | ↓ ↓ ↓ ↓ | 完全初學 |
| 下下上 | ↓ ↓ ↑ | 入門 |
| 下下下上 | ↓ ↓ ↓ ↑ | 初級 |
| 下上下上 | ↓ ↑ ↓ ↑ | 初級進階 |
| 加勒比 | ↓ — ↓ ↑ ↑ ↓ | 中級 |

## 7. 授權確認

每次輸出 PDF 前都需要確認授權。這個步驟保護老師在合規的框架下使用素材。

1. 在分析頁往下捲，找到「📜 授權確認」卡片
2. 閱讀本次練習包的授權聲明說明
3. 點「**✅ 確認授權，準備輸出**」
4. 確認後，頁面出現「✅ 授權已確認」，PDF 下載按鈕解鎖

> 授權確認只需做一次，之後重新整理也不會消失。

## 8. 老師審稿模式

分析頁右上角有「**🧑‍🏫 老師審稿**」按鈕（需先有曲譜資料）。

老師審稿模式讓您：

- 手動修改和弦進行（系統自動簡化結果不夠準確時）
- 調整刷法名稱與符號
- 補充 TAB 提示（如：「副歌先彈第一弦」）
- 加上練習說明（如：「每天 5 分鐘，只練前四小節」）
- **標記太難 → 一鍵降一個等級**
- **比較**系統原始建議 vs. 您的修改版本
- **復原**成系統原始建議

### 儲存模板

如果同一類型的學生（例如：一年級班）有固定的刷法與說明，可以把目前設定存成模板：

1. 審稿完成後，在「儲存模板」輸入名稱（例：「一年級慢版」）
2. 點「💾 儲存模板」
3. 下次做同年齡學生的練習包時，點「🪄 套用模板」一鍵帶入

### 審稿內容如何影響 PDF

儲存審稿後，**PDF 匯出會自動套用老師的修改**——和弦內容、刷法、練習說明都會反映在 PDF 上。

## 9. 慢速練習音檔

如果您在建立專案時**同時上傳了 MIDI 檔**，可以產生 3 種速度的練習音檔：

| 版本 | 速度 | 適合練習階段 |
|------|------|------------|
| 50 BPM | 極慢版 | 認識和弦、第一週 |
| 70% 速 | 七成速 | 熟悉段落後 |
| 原速 | 100% | 最終目標速度 |

每個版本都含 **1 小節倒數 click track**，方便學生跟上節奏。

### 步驟

1. 確認已完成**授權確認**（第 7 節）
2. 分析頁的「🎧 練習音檔」卡片 → 點「🎧 產生練習音檔」
3. 稍等幾秒鐘
4. 出現「50 BPM / 70% / 100%」三個下載按鈕
5. 下載 **MP3** 播放，或下載 **MIDI** 用 DAW 開啟

> **注意**：MP3 轉檔需要系統安裝 ffmpeg。若未安裝，仍可下載 MIDI 檔。  
> ffmpeg 安裝：[Windows 版下載](https://ffmpeg.org/download.html) / `brew install ffmpeg`（Mac）

## 10. 分享給學生與家長

練習包做好後，可以產生**帶時效的私人分享連結**，讓學生或家長直接在手機上開啟預覽，不需要安裝任何軟體。

### 前提條件

- 已完成授權確認
- 素材來源**不是**「私人研究」

### 步驟

1. 分析頁右上角或分享卡片，點「**建立分享連結**」
2. 選擇連結有效期間（1 天 / 7 天 / 30 天）
3. 複製出現的短網址（如：`http://localhost:8000/share/8H4Q7K2M`）
4. 把連結貼給學生或家長

### 分享頁內容

學生打開分享連結後，可以：

- **預覽 PDF**（在瀏覽器直接翻頁）
- 下載 PDF
- 下載練習音檔（若已產生）

### 撤銷連結

如果需要停止分享，在分析頁點「**撤銷分享連結**」即可。連結失效後，任何人打開都會看到「連結已失效」頁面。

## 11. Discord Bot（選用）

如果您的工作坊或家長群有 Discord，可以直接在頻道裡上傳 MusicXML 取得練習包。

### 用法

在已加入機器人的 Discord 頻道輸入：

```
/ukepack score_file: [附加你的 .musicxml 檔] source_type: public_domain confirm_license: true level: 1
```

機器人會在幾秒內回傳 PDF 檔案。

### 參數說明

| 參數 | 值 | 說明 |
|------|----|------|
| `score_file` | 附件 | 您的 MusicXML / .mxl 檔 |
| `source_type` | `public_domain` / `suno_free` / `suno_paid` / `self_created` / `licensed` / `private_research` | 素材來源 |
| `confirm_license` | `true` | 必須填 `true` 才能輸出 |
| `level` | `1` / `2` / `3` | 難度等級 |

> Discord Bot 需要主辦老師或管理員先設定好 `DISCORD_BOT_TOKEN` 環境變數並啟動機器人。

## 12. 常見問題

### Q：系統建議的 Key 不對，怎麼辦？

A：進入「**老師審稿模式**」，在「和弦內容」欄位手動修改成正確的調性再儲存即可。或者，直接在「手動輸入和弦」時，使用您希望的調性。

---

### Q：PDF 的字體太小，學生看不清楚？

A：目前 PDF 採用固定版面（A4）。如果字體過小，請在試用回饋（`feedback.md`）的 Q2 標記「不同意」，我們會在下一版本調整。

---

### Q：Level 1 和弦對我的學生還是太難，怎麼辦？

A：進入老師審稿模式，點「**⚠️ 太難：降一級**」，系統會自動切到更簡單的刷法與說明。您也可以手動編輯和弦進行，移除難和弦。

---

### Q：匯入後和弦顯示 `N.C.`（No Chord）是什麼意思？

A：`N.C.` 表示這個位置沒有和弦，或原始記譜的和弦無法對應到烏克麗麗友善版本。老師審稿模式可以手動替換成最接近的和弦。

---

### Q：PDF 多餘空白頁 / 版面跑掉？

A：這是已知問題。請在試用回饋中標注，我們會在修正版本中處理。

---

### Q：「私人研究」PDF 可以給學生嗎？

A：**不可以**。「私人研究」模式的 PDF 會印上「Private study only. Do not distribute.」警語，僅供個人研究使用，請勿分發給學生。
